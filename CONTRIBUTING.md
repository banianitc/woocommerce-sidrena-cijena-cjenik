# Doprinos projektu

Hvala na interesu za poboljšanje dodatka.

## Prijava problema

Prije otvaranja nove prijave provjerite postojeće Issues. U prijavi navedite:

- verzije WordPressa, WooCommercea, PHP-a i dodatka
- jasne korake za ponavljanje problema
- očekivano i stvarno ponašanje
- relevantne poruke pogreške bez lozinki, API ključeva, osobnih podataka ili podataka kupaca

Sigurnosne propuste nemojte objavljivati javno; slijedite [SECURITY.md](SECURITY.md).

## Promjene koda

1. Forkajte repozitorij i otvorite zasebnu granu.
2. Promjenu zadržite uskom i kompatibilnom s navedenim minimalnim verzijama.
3. Ne mijenjajte postojeće podatke korisnika bez jasne migracije.
4. Pokrenite PHP sintaksnu provjeru ili pričekajte GitHub Actions provjeru.
5. U pull requestu opišite razlog, ponašanje prije i poslije te način provjere.

Doprinosom potvrđujete da se vaš kod smije distribuirati pod licencom GPL-2.0-or-later.
